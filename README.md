# Cyber Portfolio Template

A fast, futuristic cybersecurity analyst portfolio built with Next.js, Tailwind CSS, Framer Motion, and Web Audio SFX.

## Quickstart

1. **Clone the repo:**
   ```bash
   git clone <your-repo-url>
   cd cyber-portfolio-template
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Configure Contact Form:**
   - Get a free key at [web3forms.com](https://web3forms.com).
   - Create a `.env.local` file:
     ```env
     WEB3FORMS_KEY=your_key_here
     ```
4. **Run locally:**
   ```bash
   npm run dev
   ```
5. **Personalize:**
   - Replace `public/profile.jpg` with your own image.
   - Edit your name, skills, and links in `app/page.tsx`.
